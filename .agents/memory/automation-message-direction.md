---
name: Automation message direction
description: Directional and persistence invariants for provider-independent AI and sequence messages.
---

Inbound customer events may run memory retrieval, CRM mappings, deterministic rules, and stage-trigger enrollment. Outbound sequence templates and generated replies must use an outbound-safe path that cannot run inbound CRM extraction.

**Why:** Treating outbound copy as inbound input can silently overwrite CRM data. Even while provider delivery is disabled, omitting the outbound attempt also breaks inbox history, auditing, and no-reply automation.

**How to apply:** Persist every composed outbound reply or sequence message as delivery-disabled with its conversation and available run/step correlation. Update the conversation preview. No-reply behavior derives from the latest eligible outbound message, but messages generated by a no-reply-triggered sequence are terminal and must not start another no-reply cycle. Reply-exit checks must consider the lead's latest inbound message across every workspace conversation/channel.
